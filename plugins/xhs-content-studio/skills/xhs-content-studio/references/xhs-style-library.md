# Xiaohongshu visual style library

Use this library only after the account visual intake is complete. The six systems below were abstracted from supplied cover references; they are layout and hierarchy studies, not cover templates to copy. Never reproduce another creator's mascot, face, signature illustration, logo, wording, or one-to-one composition.

## Choose a system

| Code | System | Best for | Avoid when |
|---|---|---|---|
| S01 | Blue Sketch IP | character-led explainers, fan/community series, friendly knowledge | the account has no original character or hand-drawn visual language |
| S02 | Pixel Garden Lesson | warm, beginner-friendly AI/tutorial series, recurring lessons | the idea needs sober evidence or the account cannot supply/licence pixel assets |
| S03 | Neon Collage Lab | creative tools, skills, visual experiments, high-energy launches | the post has only abstract information and no strong image material |
| S04 | Dark Research Board | analysis, technology, frameworks, industry explanation | lifestyle, gentle personal storytelling, or very dense long copy |
| S05 | Black Amber Review | rapid opinions, news takes, product/video commentary | the account has no usable portrait/product footage and does not want a host-led identity |
| S06 | World Quest Board | learning journeys, game-making, creator challenges, child-friendly education | sober research, text-heavy argument, or an account without original/authorised world imagery |

## S01 — Blue Sketch IP

**Read as:** friendly, homemade, recognisable series identity.

- Palette: paper `#FCFEFB`; sky `#BDECF7`; line `#2397B5`; deep ink `#16718A`; highlight `#F7D74B`.
- Cover skeleton: 18% hand-drawn label/title panel at top; 55% original mascot/object action in the middle; 17% hand-lettered takeaway ribbon; 10% series mark/page cue.
- Type: title in thick handwritten or rounded display style; support copy in clean sans; only 1-2 highlight boxes.
- Repeat: a consistent original mascot pose language, blue outline weight, and ribbon; vary the action, prop, and title field.
- Image rule: create a new original character system or use the account's supplied mascot. Do not imitate a reference mascot's silhouette, face, expressions, or typography.
- Best cover promise: “一个可收藏的清单 / 机制 / 解释”。

## S02 — Pixel Garden Lesson

**Read as:** a cheerful “come learn with me” tutorial world.

- Palette: forest `#376D2C`; grass `#80A93A`; parchment `#F7E5AC`; cocoa `#855020`; sky `#4F9ED3`; flower `#F4D34D`.
- Cover skeleton: full-bleed pixel environment; large parchment/plaque in the central 45%; title in 2-4 lines; a small host/avatar or tool object at lower right; 1-3 decorative badges around the plaque.
- Type: chunky rounded display face with dark cocoa shadow; title normally 12-18 Chinese characters total, not a paragraph.
- Repeat: world tiles, plaque shape, framing, and a tiny tool/host token; rotate the location/season/object to distinguish episodes.
- Image rule: use self-created/licensed pixel art, screenshots of the account's own game, or generated original pixel scenes. Do not use game sprites, game UI, or a competitor's exact garden arrangement.
- Best cover promise: “从零开始 / 跟做 / 系列第 N 课”。

## S03 — Neon Collage Lab

**Read as:** a loud, imaginative creative-tech magazine.

- Palette: ink `#12152A`; electric blue `#49D6FF`; magenta `#F14FB5`; acid lime `#D7F942`; warm orange `#FF974A`; white `#FFFDF7`.
- Cover skeleton: 60% hero visual or scene; oversized 3-6 word hook overlaps the hero; 2-4 retro UI chips/windows as evidence; a single diagonal motion path; optional portrait only when supplied.
- Type: heavy condensed / geometric display for the hook; mono or system UI face for labels; use one outlined and one filled text treatment maximum.
- Repeat: a specific window frame, sticker style, and type treatment; never repeat the entire AI collage formula.
- Image rule: require source imagery or generate a scene with a concrete art direction. Do not manufacture fake product interfaces or use a real person's face without supplied permission.
- Best cover promise: “新工具到底能做什么 / 一个反常识视觉结果”。

## S04 — Dark Research Board

**Read as:** structured, high-trust analysis with a human point of view.

- Palette: near black `#101514`; board `#1D2925`; ivory `#F7F2DE`; amber `#DF8A4A`; copper `#A95B35`; signal green `#86A977`.
- Cover skeleton: 14% small section label; 30% large 2-3 line thesis; 34% grid/diagram/card proof; 16% optional supplied headshot badge or object photo; 6% issue marker. Use a thin amber frame or grid, not both at full strength.
- Type: high-contrast white/ivory headline, amber as the single emphasis color; annotations 1/3 title size minimum.
- Repeat: a data-board grid, section tag, and one warm accent; vary diagram type (timeline, stack, comparison, system map).
- Image rule: use actual screenshots, sourced diagrams, or a clearly labelled conceptual schematic. Headshots must be supplied by the account owner.
- Best cover promise: “这件事的底层逻辑 / 一个模型或产品为什么这样运转”。

## S05 — Black Amber Review

**Read as:** concise host-led commentary, urgency, and strong opinions.

- Palette: black `#080909`; white `#F7F5EE`; amber `#F5A11B`; ember `#DB592D`; muted gray `#8E9691`.
- Cover skeleton: 12% micro label; 42% 2-4 line giant verdict on the left/top; 35% supplied host portrait, object, or screen on the opposite side; 11% one compact evidence line. Preserve empty black space.
- Type: dense bold sans for Chinese title; white for the proposition, amber for the consequence or number; no more than two font weights.
- Repeat: black ground, orange key word, host/object cutout, and upper-left section label; vary crop and object scale.
- Image rule: use the account's own portrait/footage/product screenshots. Never generate a fake talking-head image that could be mistaken for the creator.
- Best cover promise: “它真的反超了吗 / 这东西值不值得 / 上线前先看这一点”。

## S06 — World Quest Board / 世界探索任务板

**Read as:** a playable learning journey: each post feels like a clearly scoped mission inside an original world.

- Palette: deep forest `#193C2B`; moss `#5B8F52`; parchment `#F5E7B8`; river `#69B9C6`; brick `#B9573C`; ink `#163126`.
- Cover skeleton: 12–16% level/mission badge at the top; 36–42% large, high-contrast 2–3 line outcome title; 24–30% original low-poly or isometric world/game scene; 12–16% compact mission card, progress bar, map, or checklist; 6% series marker. The title must remain the first thing read.
- Type: chunky rounded display title with a dark green outline or shadow; task labels in a clean UI sans. Keep the title to 12–18 Chinese characters where possible; do not turn the task panel into tiny copy.
- Repeat: keep one original biome language, mission badge, progress device, and map/card shape. Change the mission, biome, object, route, or evidence on every cover so a series does not become one reused landscape.
- Image rule: use an account-owned game screenshot, original/licensed low-poly/isometric artwork, or a newly generated original scene. If a host/avatar appears, use only a supplied or explicitly approved likeness. Do not imitate a reference creator's child character, scene arrangement, title lettering, branded tool name, poem text, or game UI.
- Best cover promise: “完成这个小任务，你就能做出一个能玩的 ___ / 用 AI 把一个灵感变成第一关 / 第 N 关：做出 ___”。

## Selection and adaptation rules

1. Start with the user's chosen code. If they supply an existing homepage, extract its palette and hierarchy first; use the library only to fill missing decisions.
2. Present two *written* variations only when needed: keep the chosen layout family but offer a calmer or bolder palette. Do not generate finished alternatives before approval.
3. For a new series, lock four constants: palette, title treatment, recurring marker, and image/portrait rule. Vary at least two per-cover elements: hero material, title structure, diagram/object, or crop.
4. Maintain mobile legibility: 1080 x 1440, 64 px+ outside margin, title no smaller than 72 px on a cover, and supporting copy no smaller than 28 px. Treat these as starting constraints; inspect the final PNG.
5. Use a portrait only if the account provides it or explicitly approves it. A mascot must belong to the account. Competitor examples are direction, never assets.
