
## Finished carousel checklist

```
[ ] Chosen topic and angle were confirmed by the user.
[ ] Every factual claim can be traced to a source note.
[ ] Cover creates a specific reason to swipe.
[ ] Each page has one job; the reader can scan it quickly on a phone.
[ ] 1080 x 1440 (or requested dimensions), safe margins, no clipped elements.
[ ] Caption adds context rather than repeating the slides.
[ ] Ordered PNGs and the preview have been rendered and reviewed.
[ ] Visual route and style code are recorded; any reference is transformed, not copied.
```

## Caption structure

```
Hook: Restate the tension in a personal, natural sentence.
Body: Add the observation or decision process that would crowd the slides.
Source: Name and link the primary source(s); distinguish interpretation.
Question: Ask for one concrete reader experience, choice, or counterexample.
```
