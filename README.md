# 小红书内容工作室 / XHS Content Studio

把来源调研、选题确认、视觉定调、3:4 图文制作和发布包交付，变成可复用的 Codex 工作流。

它不把“随手生成一篇文案”当作完成。每次图文生产都遵循：

`账号理解 → 视觉输入 → 来源台账 → 3 个选题 → 用户确认 → 3:4 成品 → 手机端质检 → 发布包`

## 它解决什么

- 先基于真实来源和账号调性提选题，不编案例、数据或平台规则。
- 生产前强制选择视觉路线：上传已有账号素材、提供竞品参考，或选择内置 S01–S05 风格系统。
- 未经确认只交付选题卡；确认后才制作图文。
- 默认生成 1080 × 1440、3:4、手机可读的图文，且必须导出 PNG 和九宫格后才算交付。
- 支持新账号与不同内容方向，不会把一个账号的口吻硬套到另一个账号。

## 内置视觉系统

| 编号 | 风格 | 适用内容 |
|---|---|---|
| S01 | 蓝色手绘 IP | 原创角色、友好知识、社群型系列 |
| S02 | 像素花园课 | 新手教程、陪伴式连载、AI 做游戏 |
| S03 | 霓虹拼贴实验室 | 创意工具、Skill、强视觉实验 |
| S04 | 深色研究板 | 游戏机制、技术分析、行业拆解 |
| S05 | 黑橙评论台 | 热点观点、产品评测、视频评论 |

风格库只沉淀配色、层级和版式逻辑；不要复制任何参考账号的头像、IP、人物、标志、文案或完整构图。

## 安装（给使用者）

1. 克隆本仓库到本机，例如 `git clone https://github.com/<你的用户名>/xhs-content-studio-community.git`。
2. 在 Codex 的终端运行：

   ```powershell
   codex plugin marketplace add <本仓库的本地绝对路径>
   codex plugin add xhs-content-studio@xhs-content-studio-community
   ```

3. 新开一个 Codex 任务，再输入：

   ```text
   用 $xhs-content-studio 为我的账号做本周图文选题。
   ```

首次使用请一并提供以下三项中的任意一项：

- 账号头像 + 3–6 张主页/旧笔记截图；
- 3–5 个竞品封面，并说明“借什么、不借什么”；
- 选择 S01–S05 中的一个风格编号。

## 给创作者的推荐提示词

```text
用 $xhs-content-studio 为账号「账号名」做本周选题。
受众是……；我会给你这些来源……；视觉选择 S04 深色研究板。
先只给我 3 个选题卡，等我确认后再做图。
```

## 更新插件

拉取仓库更新后，在 Codex 中重新安装同名插件；然后新开一个任务，让新任务加载最新技能内容。

## 仓库结构

```text
.agents/plugins/marketplace.json     # 供 Codex 识别的社区插件市场
plugins/xhs-content-studio/          # 可安装插件源码
docs/                                # GitHub Pages 落地页
```

## 发布者说明

GitHub Pages 通过 `.github/workflows/deploy-pages.yml` 自动部署 `docs/`。首次推送后，在 GitHub 仓库 Settings → Pages 中选择 **GitHub Actions** 作为部署来源。
