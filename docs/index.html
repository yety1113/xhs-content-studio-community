工作流 / THE WORKFLOW

它不是“自动发帖器”Not a one-click posting machine.

先有能核查的材料，再有对账号有用的判断；先确认选题与视觉方向，再开始制作。最后交付的是可上传的素材包，不是模板或空泛提纲。Start with verifiable material, then make an account-specific judgment. Confirm the topic and visual route before production. The handoff is an upload-ready package—not a vague outline or raw template.

01

理解账号

读者、内容支柱、有效旧笔记、口吻和禁区。Audience, pillars, proven posts, voice, and boundaries.

02

来源台账

把事实、链接、解读和限制分开记录。Separate facts, links, interpretation, and uncertainty.

03

确认选题

固定提供 3 个结构不同的选题卡，等你选择。Three structurally different topic cards; wait for approval.

04

制作与质检

输出 3:4 PNG、九宫格、发布文案和来源注释。Render 3:4 PNGs, a contact sheet, caption, and source note.

视觉输入 / VISUAL INTAKE

每个账号，先选自己的视觉起点Every account starts with its own visual direction.

不再默认套“AI 课程模板”No generic “AI course” template by default.

生产封面前，必须从右侧三种路线中选一种。参考可以借层级和气质，但绝不复刻别人的 IP、头像、人物、标志或完整构图。Choose one route before creating covers. References can guide hierarchy and mood, but never copy another creator's IP, avatar, person, logo, or full composition.

A账号路线：头像 + 3–6 张主页或旧笔记截图Account route: avatar + 3–6 profile or post screenshots
B参考路线：3–5 个参考 + “借什么 / 不借什么”Reference route: 3–5 references + “borrow / do not copy” notes
C风格库路线：直接选择下方 S01–S05Library route: select S01–S05 below
